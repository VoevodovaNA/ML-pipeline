# ML-pipeline
Выполнен исследовательский анализ датасета Iris, применяла методы линейной регрессии, иерархической кластеризации, PCA и t-SNE, обучала модели KNN и Logistic Regression. Оценивала качество моделей с использованием cross-validation и метрик Accuracy, Precision, Recall и F1-score.

По сути это сборник из трёх лабораторных работ по машинному обучению, и почти всё построено вокруг классического датасета Iris / Ирисы Фишера.

Главное содержание такое:

Датасет: Iris — 150 объектов, 4 числовых признака: длина/ширина чашелистика и лепестка, целевой класс — один из 3 видов ириса.
EDA / анализ данных: строятся boxplot, гистограммы распределений, корреляционные матрицы; анализируются выбросы, взаимосвязи признаков и распределения.
Регрессия: в первой работе применяются линейная и множественная линейная регрессия для исследования зависимости одного признака Iris от других. Сравниваются фактические и предсказанные значения, анализируются остатки и качество модели.
Кластеризация: во второй работе используется иерархическая агломеративная кластеризация (AgglomerativeClustering) и строятся дендрограммы. Сравниваются разные способы объединения кластеров — в частности single, average, ward.
Снижение размерности: применяются PCA (Principal Component Analysis) и t-SNE, чтобы представить многомерные данные Iris в двумерном пространстве и визуально посмотреть разделение классов. На странице 12 показан PCA до двух компонент.
Классификация: используются K-Nearest Neighbors (KNN), Logistic Regression и другие. Сравниваются реальные классы и предсказания на train/test выборках.
Оценка моделей: реализованы accuracy, precision, recall, F1-score, причём для многоклассовой задачи используются weighted-метрики. Есть также cross-validation через cross_validate; в функции по умолчанию стоит cv=4. На тестовой выборке отдельно рассчитываются accuracy, weighted precision, weighted recall и weighted F1.
Визуализация: активно используются Matplotlib, Seaborn и Plotly — scatter plots, heatmaps, boxplots, гистограммы, dendrograms, 2D/3D представление данных.
Основной стек: Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, SciPy/Statsmodels, Plotly.

ПО сути был проведён классический ML pipeline: загрузка данных → EDA → анализ корреляций/выбросов → regression → clustering → PCA/t-SNE → classification → train/test → cross-validation → evaluation metrics → visualization.

Stack: Python, Pandas, NumPy, scikit-learn, SciPy, Matplotlib, Seaborn, Plotly.
